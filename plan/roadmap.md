# Roadmap

Design-level direction and parked ideas. Discrete, actionable items
belong in [GitHub Issues](https://github.com/hepplerj/sbr-website/issues)
(tagged by category + tier) — this file is for the shape of where things
are heading, not the task list.

## Climate viz suite

The West's climate story is being told through several complementary
views rather than one chart. The through-line: **"the West" is not one
climate**, and the warming shows up differently by place, by season, and
in compound (hot + dry) extremes.

Built (see `STATUS.md` for commit state):
- Warming **stripes** (original), **trajectory**, **decade-strips**,
  **compound** barcode, state-by-state **heatmap**.

Natural extensions once the keeper set is settled:
- **Precipitation heatmap** — the `heatmap` renderer is generic
  (`{rows:[{label,anomalies[]}], years:[]}`); a precip companion to the
  temperature one is mostly a build-script change.
- **Other regions / seasons** — same renderers, different NOAA slices
  (e.g. summer-only anomalies, or the Great Plains vs the Southwest).
- **True latitude bands** — the heatmap currently uses states ordered by
  latitude as a stand-in. Real latitude bands would need gridded data
  (nClimGrid) clipped to the West — a bigger data lift, only worth it if
  the states-as-bands approximation proves limiting.

## Data pipeline

- All new climate scripts stay **stdlib-only** and source from NOAA NCEI
  Climate at a Glance (regional + statewide time series), consistent
  with the existing pipeline.
- Run climate scripts with `/usr/bin/python3` (homebrew Python lacks
  working expat) — see memory.

## Cross-links to weave

- **compound (hot & dry)** years should line up with the worst years in
  **A Burning West** (wildfire) — an explicit cross-reference between
  those two sightlines would strengthen both.

## Legislation text-reuse corpus

The transcribed state sagebrush bills (`legislation.md`, 8 bills
1979–1982) drive a four-view text-analysis instrument (matrix / passage
drill / concordance / genealogy — see `STATUS.md`). Directions worth
taking:

- **Documents archive — DONE (draft).** All 8 bills are page-bundles
  under `content/documents/<slug>/index.md`, generated by
  `scripts/build_legislation_documents.py`. Remaining before publish:
  fill `source.url` on each, confirm the operative-vs-enactment dates
  (Wyoming/Utah), then flip `draft: false`. Next enhancement: **deep-link
  each genealogy node / matrix label to its document** (`/documents/<slug>/`)
  so the sightlines and archive cross-reference.
- **Consolidate the four views** into one Atlas instrument (tabs or a
  scroll sequence: matrix → genealogy → passage drill) rather than four
  separate sightlines, if they graduate from experiment to keeper.
- **Distinctive vs. commonplace phrases** — the concordance mixes
  sagebrush-specific clauses with legal boilerplate (agency names,
  constitutional stock phrases). A stopword/we-expect-this filter, or an
  IDF weighting against a general legal corpus, would surface only the
  distinctive shared language.
- **South Dakota** is in. New bills rebuild automatically via
  `make legislation-textreuse`.
- **Known gap — six more sagebrush states (parked 2026-07-06).** The
  corpus has 8 bills; six other states saw sagebrush activity in 1979–81
  and belong in it, but all predate digitized full-text systems (CA
  leginfo starts 1993; the rest are post-1990), so the text is **not on
  the open web** — adding them needs library/archive access. Roster:
  - **Washington (1980)** — highest value. Legislature **passed** a bill
    (like the enacted five), but implementation was contingent on a
    **referendum that voters rejected**. Preserved text most likely of
    the six (WA session records) — a genuine model-copy to test.
  - **California (1980)** — passed, **vetoed by Gov. Jerry Brown**;
    structurally *different* (commissioned a study + authorized the **AG
    to litigate**, not a claim-of-title copy) → would read as a
    low-similarity outlier.
  - **Colorado (1980)** — bills passed but **vetoed**; also **HJR 1006**
    (a resolution) that would cluster with North Dakota's.
  - **Idaho (1981), Montana (1981), Oregon (~1980–81)** — defeated in the
    legislature; introduced-bill text may be thin in the record.
  - **Where the text likely lives:** HeinOnline (session laws +
    law-review appendices — e.g. McGeorge L. Rev. 12:3, 1980, CA-focused,
    403 to open fetch), state **archives** bill files, or **1979–80
    Senate hearing exhibits** (HathiTrust/govinfo).
  - **To add later:** paste each full text into `legislation.md` as a new
    `# <State>` block, add its year to the `YEARS` map in
    `build_legislation_textreuse.py`, rerun the build — matrix, genealogy,
    concordance, and Documents all pick it up automatically.
